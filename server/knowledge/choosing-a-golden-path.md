# Choosing a golden path
A golden path is the supported, pre-wired way to start a service: CI, security scanning, dashboards, on-call and catalog registration come for free.

| You are building | Use |
|---|---|
| An HTTP API or backend | [Python service](golden-path-python-service) |
| A web frontend or BFF | [Node service](golden-path-node-service) |
| A queue consumer or scheduled job | [Worker service](golden-path-worker-service) |

If none fits, ask `#platform-help` **before** you start. Off-path services lose automatic upgrades and are reviewed by the platform team every quarter.

Create one from the portal (Create > pick a template) or ask your AI assistant to request it; see [How to request a new service](how-to-request-a-new-service).
