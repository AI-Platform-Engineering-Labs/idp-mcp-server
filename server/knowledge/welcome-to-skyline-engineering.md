# Welcome to Skyline engineering
Skyline Commerce runs the shop (storefront, payments, customers, notifications) on one internal developer platform. This page is the map.

## How we work
- Teams own services end to end: **team-payments** (payments-api, customers-api), **team-storefront** (orders-web), **team-platform** (notifications-worker, the platform itself).
- Everything that runs in production is in the software catalog with an owner, a tier and an on-call contact. If it is not in the catalog, it does not exist.
- We ship small changes often. Deploys follow [How to deploy and roll back](how-to-deploy-and-rollback).

## Where to start
1. Do the [first-week checklist](first-week-checklist).
2. Get access: [Access and accounts](access-and-accounts).
3. Set up your machine: [Developer environment setup](dev-environment-setup).
4. Ask in `#platform-help` when stuck. Typical answer time: under 30 minutes in working hours (09:30 to 18:30 IST).
